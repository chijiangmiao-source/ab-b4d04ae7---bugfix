# 指令 令牌 循环上界

语义说明

  • acquire（获取）：令牌须当前未持有，执行后持有；重复获取即违规（循环体内未释放会在第二轮暴露）。
  • act（操作）/ release（释放）：只能作用于当前持有令牌；release 后令牌不再持有。
  • if（条件分支）：复核将条件按两种结果展开——结果①判定成立（该路径确认令牌持有）进入 THEN；结果②判定不成立（已持有令牌保持不变）进入 ELSE 或跳过 THEN。可使用 ELSE 指令分隔两支。
  • loop（有限次数循环）：循环体按上界逐轮展开（上界 ≤ 64），每轮状态独立追踪。
  • cleanup（清理块）… end：正常流中内联跳过其主体并注册为待执行清理续体；return / abort / 脚本结束离开前按后进先出（LIFO）全部展开；支持嵌套清理块。
  • return（返回）/ abort（中止）：离开脚本前必须完成全部已注册清理，且清理结束后不得残留持有令牌；二者禁止出现在清理块内部（非法跳出清理作用域）。
  • 发现违规时给出最短指令步数、同长度保持源序（THEN 先于 ELSE）的完整逐步路径；安全时给出已穷尽的规范状态数与各出口的清理结果。
